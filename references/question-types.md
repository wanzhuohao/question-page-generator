# 题型识别参考

本文档是题型识别的**参考模式**，不是固定清单。实际使用时以图片内容为准，识别出什么就用什么。这里列出的是常见题型的识别特征和渲染方式，供识别时参考。

## 算式类

### 加法 / 减法

**识别特征**：`数字 + 数字 = ?` 或 `数字 - 数字 = ?`

**渲染**：显示算式，在线模式提供数字输入框。

### 连加连减

**识别特征**：三个或更多数字通过加减号连接。

**渲染**：同加法，算式较长时可能需要换行。

### 表内乘法

**识别特征**：`数字 × 数字 = ?`

**渲染**：同加法，使用 × 符号。

### 竖式

**识别特征**：数字上下排列，带有加减号和横线。

**渲染**：用表格模拟竖式排版，结果行提供输入框。

### 同数连加

**识别特征**：多个相同数字相加，如 `3 + 3 + 3 =`

**渲染**：同加法。

### 括号混合

**识别特征**：算式中带有括号，如 `15 - (3 + 4) =`

**渲染**：同加法，显示完整算式。

## 选择类

### 比大小

**识别特征**：`数字 ○ 数字`，○ 是待填的比较符号。

**渲染**：三个按钮（＞ ＝ ＜）。

### 填运算符

**识别特征**：`数字 ○ 数字 = 结果`，○ 需要填 + 或 -。

**渲染**：+ 和 - 两个按钮。

### 选择答案

**识别特征**：题目 + A/B/C/D 四个选项。

**渲染**：四个选项按钮，点击作答。

---

## 填空类

### 算式填空

**识别特征**：算式中有 `__` 或 `□` 表示缺失的数字。

**渲染**：将 `__` 替换为输入框。

### 乘法填空

**识别特征**：`数字 × __ = 结果`，求缺失因数。

**渲染**：同算式填空。

### 找规律

**识别特征**：一串数字，缺失其中一项。

**渲染**：显示数字序列，缺失位置用输入框。

### 问答题

**识别特征**：文字题目，需要写出答案。

**渲染**：大段文本输入框。

---

## 图形类

### 百数表

**识别特征**：数字网格，部分数字缺失。

**渲染**：CSS Grid 渲染网格，缺失位置显示输入框。

### 三角形填数

**识别特征**：三角形顶点和边中点，部分数字已知。

**渲染**：CSS 定位三角形顶点，已知数字直接显示，未知位置提供输入框。

### 方形填数

**识别特征**：正方形顶点和边中点。

**渲染**：CSS Grid 3×3 布局模拟方形。

### 三角自由填

**识别特征**：三角形 6 个位置全空，给数字池。

**渲染**：显示目标和数字池，6 个位置全空。

## 语文类

### 看拼音写汉字

**识别特征**：拼音 + 田字格。

**渲染**：显示拼音，在线模式提供选项按钮或田字格。

### 看汉字写拼音

**识别特征**：汉字，要求写拼音。

**渲染**：显示汉字，在线模式提供拼音选项。

### 组词 / 造句

**识别特征**：给出汉字要求组词或造句。

**渲染**：文本输入框。

---

## 英语类

### 单词

**识别特征**：英文单词 + 图片或中文释义。

**渲染**：显示图片/emoji + 中文，在线模式提供英文选项。

### 字母

**识别特征**：大写字母，要求识别或写小写。

**渲染**：显示大写字母，在线模式提供选项或连线。

---

## 其他

### 连线题

**识别特征**：两组元素需要连线匹配。

**渲染**：两组元素分列两侧，点击匹配。

### 阅读理解

**识别特征**：文章 + 问题。

**渲染**：显示文章和问题，文本输入或选择。

### 应用题

**识别特征**：文字描述的实际问题。

**渲染**：显示题目，文本输入答案。

### 无法识别

当无法判断具体题型时，退化为通用模式：

```json
{
  "type": "generic",
  "prompt": "题目文本内容",
  "answer": "参考答案"
}
```

**渲染**：仅展示题目和参考答案，不做交互。适用于简答题、应用题等。
